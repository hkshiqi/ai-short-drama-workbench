# 风格选择器 · 一页纸

## 三步选风格

```
① 选 1 个主风格（见下表）
② 选 0–2 个修饰层（光线 / 后期 / 媒介）
③ 复制 STYLE_PROMPT 到块卡，全剧不改字
```

## 档位与成本（量产铁律）

```
S 档  CINEMA_REAL / DOUYIN_HIGH / ROMANCE_SOFT / DRAMA_SOFT / PIXAR_3D
      一致性最高，抽 3 条就够 → 主力量产

A 档  CINEMA_COLD / CINEMA_WARM / TEAL_ORANGE / RETRO_90S_CN / RETRO_HK / ANCIENT_CN
      有辨识度，抽 4 条 → 有风格的剧

B 档  ANAMORPHIC / FILM_NOIR / SUSPENSE_DARK / WAR_DESAT / CYBERPUNK / NEON_NOIR / DREAMCORE / SCIFI_NEON
      抽 5–6 条 → 点睛镜

C 档  VHS / FILM_16MM / POLAROID / OLD_TV / ANIME_CN / ANIME_JP / INK_WASH / COMIC_CELL / GLITCH
      抽 8+ 条，一致性低 → 只做 1–2 秒的闪回/片头/情绪插入
```

**铁律：正片主体镜走 S/A 档，C 档只用于闪回/片头/转场。否则抽卡成本翻 3 倍且一致性崩。**
