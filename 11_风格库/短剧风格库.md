# 短剧风格库 · STYLE LIBRARY v1

> 第 ① 步必选参数。**风格一旦选定，全剧锁定，逐字复用到每条首尾帧提示词。**
> 与外观锁定词、场景锁定词同为「锁定层」，改 = 升版 + 重跑受影响镜。
>
> **代码实现**：`pipeline/stylelib.py`（31 主风格 + 16 修饰层，中文提示词已内置）
> **验证状态**：已接入门禁，第①步 237 项 / 第③④步 430 项 PASS

---

## 怎么用（三步）

```
① 从下面 6 组里选 1 个「主风格」（只选一个）
② 再选 0–2 个「修饰层」（光线层 / 后期层 / 媒介层），叠加在主风格上
③ 复制生成的 STYLE_PROMPT 到块卡，全剧不改字
```

**提示词拼装位置**（在 `first_frame_prompt` 里）

```
[LOCK_V1 外观] + [景别机位] + [EXP 表情] + [SCN_LOCK 环境光线] + ★[STYLE_PROMPT]★ + [画质后缀]
```

> **STYLE_PROMPT 放在环境光线之后、画质后缀之前。** 位置错了会被环境词覆盖。

# 锁定后怎么用（写进块卡）

`04_场景分镜/BLOCK_EP{NN}.csv` 增加一列 `style_prompt`（或全局写在 `01_剧本/script.json` 的 `spec.style_id`）：

```csv
...,style_id,style_prompt,style_overlays
...,CINEMA_REAL,"电影感画面，35mm 胶片质感，浅景深…","FILM_GRAIN|WINDOW_LIGHT"
```

**拼装规则**
```
first_frame_prompt = LOCK_V1 + 景别机位 + EXP表情 + SCN_LOCK环境光线 + STYLE_PROMPT + [修饰层] + 画质后缀
```

**门禁检查（第③④步自动跑）**
- [ ] 每镜 `first_frame_prompt` 含 `style_prompt` 逐字
- [ ] STYLE 位置在「环境之后、画质后缀之前」
- [ ] 全剧 `style_id` 唯一且不变
- [ ] 修饰层数量 ≤2，且同类修饰层不重复
- [ ] 风格负向词已并入 `negative` 列（自动去重）
- [ ] 画质后缀已与风格层去重（避免同一形容词稀释权重）
- [ ] 风格与题材匹配（对照速选表）

# 量产取舍建议（真实成本视角）

| 风格档 | 代表 | 一致性稳定度 | 抽卡成本 | 建议用途 |
|---|---|---|---|---|
| **S 档** | `CINEMA_REAL` `DOUYIN_HIGH` `ROMANCE_SOFT` `DRAMA_SOFT` `PIXAR_3D` | 最高 | 最低（抽 3 条就够） | **主力量产** |
| **A 档** | `CINEMA_COLD` `CINEMA_WARM` `TEAL_ORANGE` `RETRO_90S_CN` `RETRO_HK` `ANCIENT_CN` | 高 | 中 | 有辨识度的剧 |
| **B 档** | `ANAMORPHIC` `FILM_NOIR` `SUSPENSE_DARK` `WAR_DESAT` `CYBERPUNK` `NEON_NOIR` `DREAMCORE` `SCIFI_NEON` | 中 | 中高 | 点睛镜用 |
| **C 档** | `VHS` `FILM_16MM` `POLAROID` `OLD_TV` `ANIME_CN` `ANIME_JP` `INK_WASH` `COMIC_CELL` `GLITCH` | 低 | 高（抽 8+ 条） | **只做单镜/片头/闪回** |

> **量产铁律**：正片主体镜走 S/A 档，C 档只用于「闪回、片头、情绪插入、转场」这类 1–2 秒的镜。否则抽卡成本会翻 3 倍且一致性崩。
