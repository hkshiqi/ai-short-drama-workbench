# 模型选型速查卡（贴墙）

## 一句话

> **图上顶配 ｜ 视频上"可控" ｜ 音频上"国产情绪" ｜ 合成上"脚本"**
> **钱花在首帧 + 3–4 个 HERO 镜上，别花在铺量镜上。**

## 主力配置

```
剧本结构   Claude Opus / GPT-5 级
台词金句   豆包 Doubao-pro / DeepSeek
定妆锁脸   Nano Banana Pro        ← 一致性天花板
首帧定稿   Nano Banana Pro（探构图用 Seedream 省钱）
视频主体   可灵 Kling 2.5（首尾帧模式）← 继承链命门
视频铺量   即梦 Seedance / 海螺 Hailuo
空镜点睛   Veo 3 / Sora 2（一集 ≤3 镜）
配音       MiniMax Speech-02-HD / 豆包语音
BGM        Suno v5（128BPM 分轨）
合成       ffmpeg 脚本
```

## 三条选型硬理由

```
① 一致性靠图像不靠视频
   首帧脸错了 → 视频再贵也是错的
   首帧脸对了 → 便宜视频模型也能用

② 视频必须支持"首帧+尾帧"双输入
   否则尾帧继承链跑不通，一致性直接崩
   ✅ Kling / Seedance / Vidu / Runway
   ❌ Sora 2（控制差）⚠️ Veo 3（尾帧弱）

③ TTS 要的不是"像真人"，是"72 集同一个声音 + 情绪可调"
   中文情绪 → MiniMax / 豆包   ｜ 多语种 → ElevenLabs
```

## 锁脸一致性排序

```
Nano Banana Pro   ★★★★★   吃参考图 + 多角度 + 换装保脸
即梦 Seedream 4.0 ★★★★☆   中文最顺，快，便宜
Vidu 参考图       ★★★★☆   直接锁人，构图自由度低
Flux + LoRA      ★★★★☆   最稳但要自己训
MJ --cref        ★★★☆☆   美感最好，一致性最弱
SDXL+IP-Adapter  ★★★☆☆   可控但下限低
```

## 镜型分级 → 自动路由（省钱核心）

| tag | 条件 | 图 | 视频 | 抽数 | 占比 |
|---|---|---|---|---|---|
| `HERO` | 集末钩/打脸/摊牌 | NanoBananaPro | Kling Pro | 6/6 | 3–4 镜 |
| `FACE` | 正脸台词特写 | NanoBananaPro | Vidu / Kling | 4/3 | 8 镜 |
| `REACT` | 反应/听者 | Seedream | Kling 标准 | 3/2 | 多 |
| `HAND` | 手/物件/证据 | Seedream | Kling(STATIC) | 3/2 | 多 |
| `PROD` | 产品 L2/L3 | Seedream(文字准) | Kling 标准 | 4/3 | 少 |
| `ENV` | 空镜/转场 | MJ / Seedream | Veo3 / Kling | 2/2 | 少 |
| `CROWD` | 三人以上 | Seedream | Seedance | 3/2 | 少 |

## 抽卡批次（省钱三招）

```
第1轮 探构图   便宜档 4 张，只看"景别/安全区/构图"，不评脸不评画质
第2轮 定稿     选中构图 → 顶配同提示词只出 1–2 张   ← 省 50–70% 图费
第3轮 救火     加参考图权重 / 换模型 / 降表情强度 / 改景别

视频侧：先 Seedance 标准抽 2 条看"动作对不对" → 对了再 Kling Pro 出 2 条
```

## 止损线

```
连续 5 次全崩        → 换备胎，别赌第 6 次
首帧 3 张锁不住脸    → 提示词/参考图权重问题，不是模型问题
视频 6 条同一崩法    → 改 video_prompt，别继续抽
单集图费超预算 50%   → model_tag 分级没生效，检查是否把 REACT 也走了顶配
```
