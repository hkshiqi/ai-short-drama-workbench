# 模型路由表 · 每一步用哪个模型（MODEL ROUTING v1）

> 原则先说死三条：
> **① 一致性靠"图像"不靠"视频"** —— 脸在首帧锁死，视频只负责"别毁掉它"。所以选型权重最大的是**首帧图模型**。
> **② 每一环都要有"主力 + 备胎 + 省钱档"** —— 平台当天限流/涨价/改版是常态。
> **③ 抽卡阶段用便宜模型探路，定稿镜头上贵的** —— 同一镜先用省钱档试构图，构图对了再上顶配重跑。

## 二、三个"选型决策"的硬理由

### ① 为什么首帧图模型比视频模型更重要

```
视频模型只能"保持"首帧，不能"修正"首帧。
首帧脸错了 → 视频再贵也是错的。
首帧脸对了 → 便宜视频模型也能出可用的镜。
```

实测排序（锁脸一致性 / 参考图遵循度）：
```
Nano Banana Pro  ★★★★★   吃参考图 + 多角度 + 换装保脸
即梦 Seedream 4.0 ★★★★☆   中文提示词最顺，速度快，便宜
Vidu 参考图       ★★★★☆   直接锁人物，但构图自由度低
Flux + LoRA      ★★★★☆   需要自己训 LoRA，最稳但要工程
Midjourney --cref ★★★☆☆   美感最好，一致性最弱，不适合定稿
SDXL + IP-Adapter ★★★☆☆   可控性强，出图质量下限低
```

### ② 为什么视频主力必须是"有首尾帧控制"的模型

尾帧继承链是整个工作流的连贯性保证。**没有首尾帧控制的模型，继承链跑不通**，只能靠提示词硬凑，一致性直接崩。

```
必须支持：首帧图 + 尾帧图 双输入
可灵 Kling 2.5+  ✅（还带运动笔刷，可精确指定运动区域）
即梦 Seedance   ✅
Vidu            ✅（参考生视频，另一种路线）
Hailuo 02       ⚠️ 首尾帧支持弱
Runway Gen-4    ✅
Sora 2          ❌ 控制性差，别用来做继承链
Veo 3           ⚠️ 首帧强，尾帧控制弱
```

**结论：主体叙事镜 100% 走 Kling / Seedance 的"首帧→尾帧"模式。Veo/Sora 只用于不需要继承的空镜与氛围镜。**

### ③ 为什么 TTS 不用"最强通用模型"

短剧配音的需求不是"像真人"，是**"同一角色 72 集都是同一个声音，且情绪能按参数调"**。

| 需求 | ElevenLabs | MiniMax Speech-02 | 豆包语音 | 火山 |
|---|---|---|---|---|
| 中文自然度 | 良 | **优** | 优 | 良 |
| 中文情绪颗粒 | 中 | **优**（可直接给情绪标签） | 优 | 中 |
| 音色克隆 | 优 | 优 | 良 | 良 |
| 参数可控（语速/停顿/尾音） | 优 | 优 | **优** | 中 |
| 批量成本 | 高 | 中 | **低** | 低 |

**结论：中文情绪主角 → MiniMax Speech-02-HD；多语种/海外版 → ElevenLabs v3；大批量铺量 → 火山。**

## 三、三套组合（按你的账号情况直接选一套）

### 🏆 方案 A · 顶配（追求成片质感，预算不敏感）

```
剧本    Claude Opus（结构）+ 豆包（台词）
角色图  Nano Banana Pro          3 版候选 × 12 角色
首帧    Nano Banana Pro          每镜 4 张
视频    可灵 Kling 2.5 Pro（主体）+ Veo 3（空镜点睛 2-3 镜/集）
配音    MiniMax Speech-02-HD
BGM     Suno v5 + Artlist 买断垫底
对口型  即梦对嘴
合成    ffmpeg + 达芬奇调色
```
预估单集（90s）成本大头：视频 ≈ 60%（Kling Pro 3 条/镜 × 24 镜），图 ≈ 15%，其余 25%。

### ⚖️ 方案 B · 性价比（推荐，绝大多数人用这套）

```
剧本    豆包 Doubao-pro（中文最顺）+ Claude 只做大纲校对
角色图  即梦 Seedream 4.0         → 出 LOCK_V1
首帧    即梦 Seedream 4.0（省钱档试构图）→ Nano Banana Pro 只重跑选中镜
视频    即梦 Seedance 1.0 pro（铺量）+ 可灵 Kling 标准（关键镜）
配音    豆包语音 / 火山
BGM     Suno v5
合成    ffmpeg（全脚本）
```
**核心省钱技巧**：首帧先用便宜模型抽 4 张定构图 → 选中那张的提示词再上 Nano Banana Pro 出 1 张高清定稿。省 50–70% 图费。

### 🇨🇳 方案 C · 纯国产（无外网/无外币卡）

```
剧本    豆包 / DeepSeek / Kimi
角色图  即梦 Seedream 4.0
首帧    即梦 Seedream 4.0
视频    即梦 Seedance + 可灵 Kling + 海螺 Hailuo（三家互补，谁限流换谁）
配音    豆包语音 / 火山 / MiniMax
BGM     Suno（需外网）→ 无外网则 Artlist 中文代理 / 剪映音乐库 + 自己切 128BPM
合成    剪映专业版（草稿 json 可脚本化）+ ffmpeg
```

## 四、按镜型分派（块卡里加 `model_tag` 列，机器自动路由）

| 镜型标签 | 判定条件 | 图模型 | 视频模型 | 抽数 |
|---|---|---|---|---|
| `HERO` | 集末钩 / 打脸 / 摊牌 / 身份揭露 | Nano Banana Pro | Kling Pro | 图 6 / 视频 6 |
| `FACE` | 正脸台词镜，人物特写 | Nano Banana Pro | Vidu 参考生视频 或 Kling | 图 4 / 视频 3 |
| `REACT` | 反应镜、听者镜 | Seedream | Kling 标准 | 图 3 / 视频 2 |
| `HAND` | 手部 / 物件 / 证据特写 | Seedream | Kling（STATIC） | 图 3 / 视频 2 |
| `PROD` | 产品 L2/L3 | Seedream（文字渲染）/ Nano Banana Pro | Kling 标准 | 图 4 / 视频 3 |
| `ENV` | 空镜 / 环境 / 转场 | Midjourney / Seedream | Veo 3 / Kling | 图 2 / 视频 2 |
| `CROWD` | 群演 / 三人以上 | Seedream | Seedance | 图 3 / 视频 2 |

**这就是"成本控制"的全部机制**：一集 24 镜里，`HERO` 通常只有 3–4 镜，`FACE` 8 镜，剩下全是便宜的 `REACT`/`HAND`/`ENV`。

## 五、抽卡批次策略（什么时候用贵的）

```
第 1 轮 · 探构图      便宜档抽 4 张图，只看"景别对不对、人在不在安全区、构图对不对"
                     → 不评脸、不评画质（便宜模型评这些没意义）
第 2 轮 · 定稿        选中构图 → 换顶配模型，用同一提示词 + 参考图，只出 1–2 张
第 3 轮 · 救火        定稿仍崩 → 加参考图权重 / 换模型 / 降表情强度 / 改景别
```

**视频侧同理**：
```
先用 Seedance 标准模式抽 2 条看"动作对不对、有没有多手"
→ 动作对了，再用 Kling Pro 出 2 条定稿
```

## 六、模型选型的"止损线"（这几条别硬扛）

| 现象 | 说明 | 动作 |
|---|---|---|
| 某平台连续 5 次抽卡全崩 | 模型对该题材/画风有系统性缺陷 | 换备胎，别赌第 6 次 |
| 首帧 3 张都锁不住脸 | 提示词有问题，不是模型有问题 | 回查 `LOCK_V1` 是否被改写、参考图权重是否够 |
| 视频 6 条全是同一个崩法 | 运动描述写错了 | 改 `video_prompt`，不是继续抽 |
| 平台涨价/限流 | 常态 | 备胎链自动接管（按上表 🥈 顺移） |
| 单集图费超预算 50% | `model_tag` 分级没生效 | 检查是否把 `REACT` 镜也走了顶配 |

## 九、一页结论

```
剧本结构   Claude/GPT-5 级推理模型
台词金句   豆包 / DeepSeek（中文）
定妆锁脸   Nano Banana Pro  （一致性天花板）
首帧定稿   Nano Banana Pro  （省钱档 Seedream 先探构图）
视频主体   可灵 Kling 2.5 首尾帧模式（继承链命门）
视频铺量   即梦 Seedance / 海螺 Hailuo
空镜点睛   Veo 3 / Sora 2（一集≤3 镜）
配音       MiniMax Speech-02-HD / 豆包语音
BGM        Suno v5（128BPM 分轨生成）
合成       ffmpeg 全脚本
```

**一句话**：**图上顶配，视频上"可控"，音频上"国产情绪"，合成上"脚本"。**
钱要花在首帧和 3–4 个 HERO 镜上，别花在铺量镜上。
