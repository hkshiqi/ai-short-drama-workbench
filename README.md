# AI 短剧工作台 · AI Short-Drama Workbench

> 把「一个故事」变成「一部能发的短剧」的六步工作流 + 可执行工具链。
> **六步：剧本 → 视觉圣经 → 首尾帧+块卡 → 镜头圣经 → 抽卡+验证 → 合成交付**
> 每步都是硬门禁，全绿才允许进下一步；当前全流程 **830 项门禁检查**。

---

## 一句话逻辑

> **把所有"创作决策"往前压到 ①②③④，让 ⑤⑥ 变成纯工程执行。**
> 执行期还要改创作，说明前三层没定死 —— 回退，不要现场拍脑袋。

---

## 三层锁定

```
第一层 故事层   ① 剧本         锁：剧情/台词/情绪相位/15s切块/风格
第二层 视觉层   ② 视觉圣经     锁：人长什么样/场景/物品/声音
第三层 镜头层   ③④ 块卡+镜卡   锁：每帧长什么样/每秒听什么
执行层          ⑤⑥ 抽卡拼接    只执行，不创作。执行期不许改前三层
```

## 三条贯穿铁律

1. **锁定词逐字复现** —— 人物一致性只靠这个，改一字就变脸
2. **音频先行** —— TTS 在视频抽卡之前，否则全程返工
3. **15s 块 = 唯一生产/验收/返修单元** —— 坏了只重抽那一块

---

## 六步流程

| 步 | 做什么 | 产物 | 门禁 |
|---|---|---|---|
| ① | 故事 → 剧本（含 15s 切块 + 块蓝图 + 风格定档） | `script.json` / `EP*.md` | 237 项 |
| ② | 视觉圣经（角色九宫格 / 场景三视图 / 物品三视图 / 音色） | 三份锁定词 + 待出图清单 | 50 项 |
| ③④ | 块级+镜级首尾帧 + 块卡（视觉/音频/时长同卡）+ 提示词拼装 | `BLOCK_EP*.csv`（60 张首尾帧） | 430 项 |
| ⑤A | 音频先行（TTS 吸网格 → 回写块卡 → BGM 48 小节） | voice/bgm/sfx/srt | 46 项 |
| ⑤C | 六道一致性验证（计划vs实际/接缝/角色/物品场景/声音/时长） | 验证台账 + 报告 | 6 道 |
| ⑥ | 合成 → 混音 ducking → 烧字幕 → 拼接 → 12 项交付验收 | `EP01.mp4` | 29 项 |

**六个决策点**（只有这 6 处需要人拍板）：剧本 / 选脸 / 首尾帧 / 提示词 / 试跑块 / 成片签收。

## 风格库（31 种主风格 + 16 修饰层）

三层必须拆开定，混在一起会打架：

| 层面 | 决定什么 | 落在哪 |
|---|---|---|
| **视觉风格** | 画面长什么样 | `spec.style.style_id` → 进提示词 |
| **叙事风格** | 怎么讲故事 | `script.json` 的 `narrative` |
| **情绪风格** | 观众该有什么感受 | 每集 `hard_hook.type` + 块级 `phase` |

**6 组 31 种**：A电影写实(8) / B怀旧复古(7) / C类型片(7) / D动画(6) / E风格化(4) / F竖屏短剧(4)

**档位与成本铁律**：
```
S 档量产主力  CINEMA_REAL / DOUYIN_HIGH / ROMANCE_SOFT / DRAMA_SOFT / PIXAR_3D
C 档只做闪回  VHS / GLITCH / INK_WASH / COMIC_CELL / CLAY ...（1–2 秒的镜）
```
C 档用在正片主体镜 → 抽卡成本翻 3 倍且一致性崩。

详见 `11_风格库/短剧风格库.md`、`pipeline/stylelib.py`。

## 技术要点（踩过坑才写进来的）

| # | 要点 | 坑在哪 |
|---|---|---|
| 1 | 所有 ffmpeg/ffprobe 走 `mediautil`（bytes + DEVNULL） | 中文路径时长全读成 0；**ffprobe 不支持 `-nostdin`** |
| 2 | 取色走 `imgutil`（一图一次进程） | 逐区域调 ffmpeg → 600+ 次进程，验证跑不动 |
| 3 | 合规扫描走 `compliance`（上下文 + 白名单） | 裸"最"字把"最后一单"判成违规 |
| 4 | 表情跨级按角色分组判 | 跨角色混判 → 大面积误报 |
| 5 | 次要运动按场景映射 | 室内戏写出"雨水滴落" |
| 6 | 剧本门禁含"单块台词 ≤44 字" | 台词塞不进 8 小节，到音频层才炸 |
| 7 | 时长按景别容量上限分配 | 特写挂 5.6 秒观众直接出戏 |
| 8 | 块接缝按"同场景+同角色延续"判 | 换角色被判成人物漂移 |
| 9 | 风格层与画质后缀去重 | 同一形容词出现两次会稀释权重 |

完整记录见 `pipeline/流程测试报告.md`。

## 时间系统

```
128 BPM → 1 小节 = 1.875s → 8 小节 = 15.000s = 1 块
90s 集 = 6 块；120s = 8 块；60s = 4 块
单镜时长只能是 1.875 / 3.750 / 5.625s
```

所有时长、BGM 卡点、字幕、切点全部吸附这个网格。**不再有"这镜 4.3 秒怎么办"的问题。**
