## 二、发现并修复的 9 处真实缺陷

### 缺陷 1 · 表情跨级判定错在"按块混判"

**现象**：B06 里反派 `EXP_SHOCK_H`(3) 与主角 `EXP_CONTEMPT_L`(1) 被判"跨级超限"而报错。
**病因**：门禁把一块内所有镜的 `expr_int` 拉平求 min/max。
**修法**：**按角色分组**判跨级——每个角色有各自的情绪弧线，不能混判。
```python
per_char: dict[str, list[int]] = {}
for r in shots:
    for c in r["char_ids"].split("|"):
        per_char.setdefault(c, []).append(int(r["expr_int"]))
for c, ints in per_char.items():
    assert max(ints) - min(ints) <= 1
```
**这条已写入 `04_场景分镜/人物表情控制规范.md` 的门禁章节。**

---

### 缺陷 2 · 室内场景写了"雨水滴落"

**现象**：`SCN_ROOM_DUSK`（室内客厅）的 `video_prompt` 里出现"雨水从发梢滴落"。
**病因**：次要运动描述是全局常量。
**修法**：**场景 → 次要运动**映射表：
```python
SECONDARY_BY_SCENE = {
    "SCN_ALLEY_NIGHT": "雨水从发梢滴落，衣角被风带动，地面积水有细微涟漪",
    "SCN_ROOM_DUSK": "窗帘被气流带动轻晃，细微浮尘在光柱里飘动",
}
```
并加门禁：非降雨场景的 `video_prompt` 不得含"雨水"。

---

### 缺陷 3 · 台词塞不进 8 小节（剧本层容量约束缺失）

**现象**：B03 四句台词按配音吸附后总长 11.25s > 15s 块容量，收口失败。
**病因**：① 剧本层没有任何"字数上限"，⑤ 音频层才发现塞不下。
**修法**：在**第①步剧本门禁**加硬约束——
```
单块台词字数 ≤ 44 字
（中文语速约 4.2 字/秒，8 小节 15s 可容 ~63 字，留 30% 呼吸余量 → 44 字硬上限）
```
**这是"音频先行"能成立的前提**：剧本写的时候就保证台词塞得进块。

---

### 缺陷 4 · 时长分配把余量全塞给无台词镜

**现象**：1.875s 的大特写（ECU）被拉到 5.625s，特写挂 5 秒观众直接出戏。
**病因**：收口算法只做"给无台词镜加长"，没有表演合理性上限。
**修法**：**按景别设容量上限**，按权重分配——
```python
FACE_CAP = {"ECU": 2, "CU": 2, "MS": 3, "MFS": 3, "FS": 3, "ELS": 3}  # 小节
```
分配顺序：先定有台词镜的语音下限 → 余量按容量上限加权轮分配 → 收口失败则报错回第①步。

---

### 缺陷 5 · 块间接缝按"绝对色相"判定 → 大面积误报

**现象**：20 镜被判接缝失败，实际都是"跨块换了角色"。
**病因**：判据是"前块尾帧色相 ↔ 后块首帧色相"，跨角色必然不同。
**修法**：接缝比的是**"同一角色的外观是否延续"**：
```
同场景 + 同角色（且该角色是后块首镜主角）→ 才比角色签名色相
换角色 / 换场景 → 不构成漂移，跳过
```

---

### 缺陷 6 · 禁用词裸子串匹配把"最后"判成"最"

**现象**：`禁用词扫描命中 ['最']`，来源是台词"最后一单。"
**病因**：禁用词表里放裸"最"字做子串匹配。
**修法**：**带上下文的合规扫描器**（`pipeline/compliance.py`）：
- 白名单遮蔽：`最后/最初/最近/最终/最后一次` 先替换掉
- 绝对化：正则匹配 `最好|最强|最美|最佳|最高级|最低价|销量第一|全国第一…`
- 无条件禁用：`顶级|国家级|100%|彻底|永久|唯一|史上…`
- 疗效承诺：`根治|治愈|祛斑|见效|无副作用|医用级|疗程…`

---

### 缺陷 7 · Windows 中文路径下 ffprobe 静默返回 0

**现象**：`实测 0.000s vs 块卡 3.750s`，全片 F 道全红。
**病因**：两层坑叠加——
1. `subprocess` 默认用 GBK 解码 stdout，中文路径/输出导致 `float()` 失败
2. **`ffprobe` 不支持 `-nostdin`**（那是 ffmpeg 的选项）→ rc=1，stdout 为空
**修法**：`pipeline/mediautil.py`
```python
subprocess.run(args, capture_output=True, encoding=None,
               stdin=subprocess.DEVNULL)   # 用 DEVNULL 代替 -nostdin
txt = out.decode("ascii", "ignore").strip()  # 全程 bytes → ascii
```
**这条对工作台是硬要求：所有调 ffmpeg/ffprobe 的地方必须走 `mediautil`，不许裸调。**

---

### 缺陷 8 · 逐区域调 ffmpeg 取色 → 600+ 次进程，验证跑不动

**现象**：验证 24 镜要 10 分钟以上，终端像卡死。
**病因**：每张图每个区域起一次 ffmpeg（主色、角色块、景别条、表情条…）。
**修法**：`pipeline/imgutil.py` —— **每张图只起 1 次 ffmpeg**，缩到 72×128 读 raw RGB，后续全在 Python 内存算。
**提速约 20 倍**（24 镜验证 11s 完成）。

---

### 缺陷 9 · 首尾帧只做块级不够（本次确认）

**结论**：块级 12 张 + 镜级 48 张，两层都做才能覆盖全片 1380 帧的每一处接缝。
**验证**：B03 第 4 镜是主动断链点（MS→MS + 换机位），若不断链，该镜必漂。
