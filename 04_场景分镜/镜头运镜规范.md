# 镜头与运镜规范（S4 子规范）

> 一句话：**AI 短剧里，运镜是成本项不是炫技项。**
> 真实拍摄靠运镜造情绪，AI 生成靠运镜造事故。这份文件定死：哪些能用、怎么写进提示词、崩了怎么救。

---

## 一、景别（shot_size）· 六级制

| 代号 | 名称 | 取景 | AI 稳定性 | 情绪职能 | 短剧占比建议 |
|---|---|---|---|---|---|
| `ECU` | 大特写 | 眼/手/唇/产品细节 | ★★★★★ 最稳 | 情绪爆点、产品特写、证据展示 | 15% |
| `CU` | 特写 | 头肩 | ★★★★★ | 台词镜、表情镜 | **40%（主力）** |
| `MS` | 中景 | 腰以上 | ★★★★☆ | 对话、动作起势 | 25% |
| `MFS` | 中全 | 膝以上 | ★★★☆☆ | 交代关系、双人同框 | 12% |
| `FS` | 全景 | 全身 | ★★☆☆☆ | 交代空间、人物出场 | 6% |
| `ELS` | 大全 | 环境为主 | ★★☆☆☆ | 转场、氛围、时空交代 | 2% |

**铁律**
1. **CU/ECU 合计 ≥ 50%**。竖屏手机屏只有一臂距离，中景以下观众看不清表情，情绪就传不到。
2. 每集 `FS`+`ELS` ≤ 2 镜，且只用在必须交代空间的时刻。
3. 特写不拍全身，全景不拍表情——景别和职能错配就是白烧一条。

## 二、机位与角度（camera）

| 代号 | 中文 | 提示词写法（中） | 提示词写法（EN） | 用途 / 暗示 |
|---|---|---|---|---|
| `EYE` | 平视 | 平视机位，镜头与人眼齐高 | eye-level shot | 中立、真实，**默认值** |
| `LOW` | 仰拍 | 低机位仰拍，微微上仰 | low-angle shot, slight upward | 压迫感、强大、反派登场 |
| `HIGH` | 俯拍 | 高机位俯拍，向下俯视 | high-angle shot, looking down | 弱势、被审判、可怜 |
| `BIRD` | 顶俯 | 垂直俯拍 | top-down shot | 空间关系、孤立感 |
| `OTS` | 过肩 | 过肩镜头，前景是A的肩部虚化，焦点在B脸上 | over-the-shoulder shot, foreground shoulder blurred | **正反打标配，AI 友好度高** |
| `PROFILE` | 侧脸 | 四分之三侧脸 | three-quarter profile | 犹豫、隐瞒、心事 |
| `BCK` | 背身 | 背对镜头，只见背影与后脑 | back view, seen from behind | 神秘、离别、隐藏表情 |
| `POV` | 主观 | 第一人称视角 | POV shot | 代入感、看手机/看信 |
| `DUTCH` | 斜角 | 镜头倾斜 15 度 | dutch angle | 失衡、疯狂、危机（**慎用，AI 容易歪成错误**） |

**角度情绪对照（选角度的唯一依据）**

```
观众要觉得角色「强」→ LOW / EYE 微仰
观众要觉得角色「惨」→ HIGH
观众要「替他尴尬」→ OTS 或 PROFILE（看不到完整表情，替他难受）
观众要「被压」  → HIGH + 大特写（逼近）
观众要「窥视」  → OTS + 前景遮挡（门缝/肩/玻璃）
```

**AI 稳定性排名**：EYE / OTS > PROFILE > LOW / HIGH > BCK / POV > DUTCH / BIRD
→ 一集里 `DUTCH` 最多 1 镜，`BIRD` 不用（直接崩）。

## 三、运镜（move）· 能跑 / 不能跑两栏

### ✅ 白名单（可放心写，图生视频成功率高）

| 代号 | 中文 | 提示词（中） | 提示词（EN） | 幅度上限 | 情绪 |
|---|---|---|---|---|---|
| `STATIC` | 固定 | 镜头固定不动 | static camera, locked shot | 0 | **默认，占 60%+** |
| `PUSH_S` | 缓推 | 镜头极缓慢推近 | very slow push in | 5s 内景别进半级 | 紧张升级、聚焦真相 |
| `PULL_S` | 缓拉 | 镜头极缓慢拉远 | very slow pull out | 半级 | 抽离、孤独、失落 |
| `PAN_S` | 缓摇 | 镜头缓慢左右摇 | slow pan left/right | ≤15° | 扫视环境、寻找 |
| `TILT_S` | 缓仰俯 | 镜头缓慢上仰/下俯 | slow tilt up/down | ≤15° | 从脚到脸（仰）/从脸到地（俯） |
| `TRACK_S` | 缓跟 | 镜头跟随人物缓慢横移 | slow tracking shot following | 人物只走 2–3 步 | 并肩走、赶路 |
| `HANDHELD_L` | 轻手持 | 轻微手持晃动，真实感 | subtle handheld camera shake | 极小 | 纪实感、慌乱前奏 |
| `RACK` | 移焦 | 焦点从前景移到人物脸 | rack focus from foreground to subject | 一次 | 揭示、注意力转移 |

### ❌ 黑名单（写了就是白烧额度）

| 运镜 | 为什么崩 | 替代方案 |
|---|---|---|
| 快速推拉 / 急推（crash zoom） | 中间帧全废，脸糊成团 | 用**剪辑跳切**：CU → ECU 硬切，观众感受就是急推 |
| 甩镜 / 快速横摇（whip pan） | 运动模糊崩坏，结构散 | 硬切两个固定镜，中间加 `whoosh` 音效 |
| 环绕运镜（orbit / 360°） | 背景全变形，人物变脸 | 用 2–3 个不同角度固定镜剪出"环视感" |
| 升降镜头（crane / 摇臂） | 大范围透视变化必崩 | 高低机位硬切 |
| 手持奔跑跟拍 | 主体+背景双重崩 | 固定机位拍人物跑出画，下一镜拍背影跑入画 |
| 变焦（zoom） | AI 分不清推轨和变焦，出来是糊的 | 一律用 `PUSH_S`（虚拟推轨） |
| 长时间一镜到底（>6s） | 时间越长漂得越狠 | 拆成 2–3 镜，剪辑接上 |
| 镜头穿过物体（穿门/穿玻璃） | 中间帧完全乱 | 硬切 |

**一句话判据**：5 秒内镜头位置变化超过"半级景别"或"15 度角"，就不要写。

## 四、提示词落位（首帧 vs 视频，别搞混）

```
first_frame_prompt  =  锁定词 + 景别 + 机位角度 + 人物状态 + 环境 + 光线 + 画质后缀
video_prompt        =  主体动作 + 次要运动 + 运镜 + 时长感
```

**运镜只写在 `video_prompt`，不写在 `first_frame_prompt`。**
首帧是静态图，写"缓推"它理解不了；写进去只会污染构图。

### 标准写法示例

```
# first_frame_prompt
28岁亚洲男性，窄长脸，颧骨清晰，内双细长眼，薄唇，短寸黑发，肤色偏黄白，身高178偏瘦肩宽，左手腕旧钢表，右眉尾浅疤，
特写镜头，平视机位，他抬眼直视镜头，眼底压着怒，嘴唇微抿，
城中村巷口夜雨，身后是模糊的品红霓虹，
顶灯冷白从上方打下来，脸侧有品红反光，
电影感，35mm胶片质感，浅景深，高细节皮肤纹理，自然光，8k，竖构图9:16

# video_prompt
他眼神极缓地从下往上抬起，幅度很小，雨水从发梢滴落，镜头极缓慢推近，5秒。
```

### 英文版（MJ / Runway / Sora）

```
# first_frame_prompt (EN)
28-year-old East Asian man, narrow long face, defined cheekbones, thin double-eyelid eyes, thin lips, short buzz-cut black hair, warm pale skin, lean 178cm broad-shouldered build, worn steel-band watch on left wrist, faint scar on right eyebrow tail,
close-up shot, eye-level, he looks up straight into the lens, restrained anger in his eyes, lips slightly pressed,
narrow alley at night in rain, blurred magenta neon behind him,
cool white top light, magenta rim light on cheek,
cinematic, 35mm film grain, shallow depth of field, detailed skin texture, natural light, 8k, vertical 9:16

# video_prompt (EN)
He slowly raises his gaze from low to the lens, minimal movement, rain dripping from his hair tips, very slow push in, 5 seconds.
```

## 五、运镜与剪辑的配合（这条决定成片"像不像片子"）

1. **同向不接**：两个缓推不要背靠背接。推 → 固定 → 拉，才有呼吸。
2. **动静相间**：一集里 `STATIC` 占 60% 以上，`PUSH_S` 只留给"要观众注意"的那一下。
3. **运镜指向信息**：推 = 有东西要看；拉 = 有东西在失去；摇 = 有东西要找。**没有信息就不要运镜。**
4. **情绪高点用固定 + 特写**，不用运镜。观众情绪起来时晃镜头会打断。
5. **场景切换用硬切 + 音效**，不用运镜过渡（AI 过渡运镜必崩）。
6. `BEAT_DROP`（BGM 卡点）落在**切点**上，不落在运镜中段。

## 六、按剧型的运镜模板（直接抄）

### 都市甜宠
```
男主登场：LOW + MS + PUSH_S（仰拍缓推，气场）
女主反应：CU + EYE + STATIC（稳住，让观众看表情）
心动瞬间：ECU 手部相触 + STATIC + RACK 到脸
对视：OTS 正反打，两侧都 STATIC
```

### 逆袭打脸
```
被打压：HIGH + CU + STATIC（俯视特写 = 弱）
反派得意：LOW + MS + 微 PUSH_S（仰拍 = 他自以为强）
证据落地：ECU 手机屏/文件 + STATIC + 硬切
摊牌：EYE + CU + PUSH_S（推近 = 压向反派）
打脸反应：HIGH + CU + PULL_S（拉远 = 他塌了）
```

### 悬疑反转
```
异常提示：ECU 细节 + STATIC（让观众自己发现）
寻找：PAN_S ±15° + 空镜
揭示：RACK 移焦 + CU
假答案：PROFILE + STATIC（侧脸 = 有隐瞒）
```

### 复仇/压抑
```
常态：HIGH + MS（永远被压）
爆发前：ECU 眼睛 + STATIC + 无 BGM
爆发：EYE + CU + PUSH_S + BEAT_DROP
```

### 产品 L2/L3
```
L2 使用：ECU 手部 + STATIC（手最稳）
L3 卖点：ECU 产品 + 360 不可用 → 用「PUSH_S 缓推 + 产品轻转（≤30°）」代替旋转
产品与环境：MS + STATIC，产品在画面 1/3 位置，不抢人脸
```

## 七、常见翻车与修法（照着改就行）

| 症状 | 病因 | 修法 |
|---|---|---|
| 脸在运镜中变形 | 推拉幅度过大 | 改 `STATIC`，把"接近"交给剪辑：CU 硬切 ECU |
| 人物跑着跑着变两个人 | 多主体 + 位移 | 拆成"跑出画"+"跑入画"两镜 |
| 手部糊成一团 | 运动中拍手 | 手部一律 `STATIC` + ECU |
| 背景变形扭曲 | 环绕/摇臂/大幅摇 | 换固定机位，用多个角度剪 |
| 画面上下抖 | 手持写得过重 | `HANDHELD_L` 只在前 2 秒，或直接去掉 |
| 转场糊成一片 | 用了运镜过渡 | 硬切 + 音效 |
| 同场景两张脸光线不同 | 光线词每镜各写一遍 | 把光线词提到 `场景设定.md`，全场景共用 |
| 侧脸认不出是谁 | `DUTCH`/`PROFILE` 过度 | 侧脸限制在 3/4，全侧脸一集 ≤1 镜 |
| 5 秒镜后半段崩 | 时长超限 | 全部压到 2–5s，长镜头靠剪辑堆 |

## 八、镜头表打分（我在 S4 出口自动跑）

| 项 | 判据 | 权重 |
|---|---|---|
| CU+ECU 占比 | ≥50% | 权重最高 |
| STATIC 占比 | ≥60% | 高 |
| 黑名单运镜 | = 0 次 | **一票否决** |
| 单镜时长 | 全部 2–5s | 一票否决 |
| DUTCH/BIRD | ≤1 次 | 中 |
| 同场景运镜连续性 | 无"推→推"背靠背 | 中 |
| 运镜有无信息理由 | 每次运镜能说出"因为要看X" | 中 |
| 运镜与 BGM 卡点 | 卡点落在切点 | 低 |
