# 镜头运镜速查卡（打印贴墙版）

## 一页纸

```
景别    ECU 大特写 > CU 特写 > MS 中景 > MFS 中全 > FS 全景 > ELS 大全
配比    ECU 15% | CU 40% | MS 25% | MFS 12% | FS 6% | ELS 2%
        → CU+ECU 必须 ≥50%

机位    EYE 平视(默认)  LOW 仰(他强)  HIGH 俯(他惨)  OTS 过肩(正反打)
        PROFILE 3/4侧(隐瞒)  BCK 背身  POV 主观  DUTCH 斜(一集≤1)  BIRD 不用

运镜    STATIC 固定  ← 60%以上，默认
        PUSH_S 缓推  只看这一下
        PULL_S 缓拉  失去
        PAN_S  缓摇  ≤15°
        TILT_S 缓仰俯 ≤15°
        TRACK_S 缓跟 走2-3步
        HANDHELD_L 轻手持（前2秒）
        RACK 移焦（一次）
```

## 三个"不许"

```
× 5秒内变半级以上景别 / 转15度以上     → 崩
× 环绕·摇臂·甩镜·急推·变焦·一镜到底·穿物 → 白烧额度
× 运镜写进 first_frame_prompt          → 污染构图
```

## 一句话判据

> 没有"要看的东西"，就不要运镜。
> 推=有东西要看｜拉=有东西在失去｜摇=有东西要找｜固定=让人看表情。

## 情绪→角度对照

```
要让观众觉得他强    → LOW / EYE 微仰
要让观众觉得他惨    → HIGH
要让观众替他尴尬    → OTS / PROFILE
要让观众被压        → HIGH + 大特写
要让观众窥视        → OTS + 前景遮挡
```

## 崩了怎么救

```
脸变形      → 改 STATIC，接近交给硬切（CU→ECU）
人变两个    → 拆"跑出画"+"跑入画"
手糊        → 手部一律 STATIC + ECU
背景扭曲    → 换固定机位，多角度剪
转场糊      → 硬切 + whoosh
光线不连    → 光线词提到 场景设定.md 全场景共用
侧脸认不出  → 侧脸限 3/4，全侧一集≤1
5秒后崩     → 全压 2–5s
```

## 剧型模板（最省事的四套）

```
甜宠   男主 LOW+MS+推 ｜ 女主 CU+EYE+固定 ｜ 心动 ECU手+固定+移焦脸
打脸   打压 HIGH+CU ｜ 得意 LOW+MS+微推 ｜ 摊牌 EYE+CU+推 ｜ 塌 HIGH+CU+拉
悬疑   提示 ECU细节+固定 ｜ 寻找 缓摇15° ｜ 揭示 移焦+CU ｜ 假答案 3/4侧+固定
压抑   常态 HIGH+MS ｜ 爆发前 ECU眼+固定+无BGM ｜ 爆发 EYE+CU+推+BGM DROP
```
