# 首尾帧规范（第 ③ 步）· 块级锚点 + 镜级继承

> 一句话：**首尾帧不是"参考图"，是"合同"。**
> 第 ③ 步出的每一张 IN/OUT，都是第 ⑤ 步抽卡的验收标准。实际生成的东西和这张对不上，就是不合格。
> **这就是你要的"最大程度视频连贯性"的可执行答案。**

---

## 一、双层结构（关键）

| 层 | 粒度 | 数量（90s 集） | 作用 |
|---|---|---|---|
| **块级首尾帧** | 15s 块 | 2 张 × 6 块 = **12 张** | **块间接缝锚点**。B01_OUT 与 B02_IN 必须接得上 |
| **镜级首尾帧** | 单镜 | 2 张 × 24 镜 = **48 张** | **块内接缝**。SH0N_OUT 与 SH0(N+1)_IN 必须接得上 |

**为什么必须两层**：
只做块级 → 块内 4–6 镜之间照样漂，观众在 15 秒内就看到"换了个人"。
只做镜级 → 块与块之间没有共同锚点，6 块拼起来像 6 段。

**两层都做 → 从第 1 帧到第 1380 帧（92s），每一处接缝都有明确的视觉承诺。**

---

## 二、块级首尾帧（块锚点）

每块两张：

```
10_首尾帧/EP01/B01_IN.png    块的视觉起点（= 块首镜的 SH01_IN）
10_首尾帧/EP01/B01_OUT.png   块的视觉终点（= 块末镜的 SH04_OUT）
```

### 生成方法
```
B01_IN  = LOCK_V1（该镜出场角色）
        + SCN_LOCK_V1（该场景）
        + 景别 + 机位 + EXP 表情
        + 画质后缀
        参考图：FACE_REF_{ID}.png（图生图）

B01_OUT = 在 B01_IN 的提示词基础上，改三处：
          ① 表情 → 该镜结束时的表情（跨级 ≤1）
          ② 姿势/视线 → 该镜结束时的状态
          ③ 画面元素 → 块尾必须出现/消失的东西（门开了、人转身了）
        参考图：B01_IN.png（**关键：以首帧为参考，保证同光同衣同姿态基调**）
```

### 块间接缝校验（**这一步做完才能进第 ④ 步**）

```
B01_OUT  ↔  B02_IN   逐项核 6 项：

□ 光线方向    光源从哪来，两图一致吗
□ 色温        冷/暖偏色一致吗
□ 服装        同一套 OUTFIT_* 吗
□ 姿态        能接上吗（前块人往左走，后块人还得在左侧）
□ 道具        手里拿的东西、桌上的东西对得上吗
□ 表情基调    跨级超过 1 级吗
```

**不一致 → 重出 B02_IN。** 这一步改图不要钱，等到视频阶段才发现要重跑 6 条视频。

## 三、镜级首尾帧（块内继承链）

```
SH01_IN → SH01_OUT ═══ SH02_IN → SH02_OUT ═══ SH03_IN → ... → SH04_OUT
                                                              ↑
                                                         = B01_OUT
```

### 生成方法
```
SH0N_IN  ← 参考图：SH0(N-1)_OUT.png（图生图），提示词加"延续上一镜的姿势/光线"
         ← 若是链首（SH01_IN）→ 参考图用 FACE_REF_ID.png，且必须 = B{NN}_IN

SH0N_OUT ← 参考图：SH0N_IN.png（同镜内，保证同光同衣）
         ← 提示词改：表情（跨级≤1）+ 结束姿势 + 结束画面元素
```

### 链长上限 4 镜（硬规则）
一块 4–6 镜，所以块内可能断一次链。**连续继承超过 4 镜必漂。**

### 必须断链重开的 5 种情况
| 情况 | 原因 | 断链后用什么参考 |
|---|---|---|
| 换场景 | 环境全变，继承带脏背景 | 新场景 MAIN.png + FACE_REF |
| 换装 | 服装不一致直接穿帮 | 该服装的 GRID_OUTFIT_*.png + FACE_REF |
| 时间跳跃（夜→晨） | 光线冲突 | 新光线的 LIGHT_REF + SCN_LOCK |
| 上一镜尾帧已崩（脸/手） | 崩帧传染整块 | FACE_REF 重开 |
| ECU 跳 FS | 参考图信息量差太大，继承反而干扰 | FACE_REF + 场景三视图 |

## 四、块卡（块级视听蓝图）· 视觉 / 音频 / 时长同卡锁定

> **关于你说的"首尾帧包含 BGM"**：BGM 没法放进图片。
> 正确落位是：**同一份块卡里，视觉列锁图片、音频列锁声音、时长列锁节拍** —— 三者一起冻结、一起确认。
> 这样"一块"在进入第 ⑤ 步之前，视觉和听觉都已经是确定的了。

`04_场景分镜/BLOCK_EP{NN}_B{NN}.csv`，**三组列**：

### ① 视觉列
```csv
ep,block,shot,frame_in,frame_out,shot_size,camera,move,expr_code,expr_int,char_ids,outfit,product,level,model_tag
1,1,1,B01_SH01_IN.png,B01_SH01_OUT.png,ECU,EYE,STATIC,EXP_GRIEF_M,1,C_LEAD,OUTFIT_A,无,无,FACE
```

### ② 音频列
```csv
line,sub_text,voice_emotion,sfx,bgm_layer,bgm_cue,ambience
最后一单。,最后一单。,EXP_GRIEF_M,雨声底噪,PAD,进,雨夜环境
```

### ③ 时长列
```csv
bar_start,bar_len,dur_bar,dur_sec
1,2,2,3.750
```

**规则**
- `dur_sec = dur_bar × 1.875`（128BPM → 1 小节 1.875s → 8 小节 = 15.000s）。**不许手填秒数。**
- `frame_in` / `frame_out` 必须是**真实存在的文件路径**（第 ③ 步产物）
- `bgm_cue` 必须能在 `配乐卡点表_EP{NN}.csv` 里找到
- `expr_int`：1 轻 / 2 中 / 3 重

## 五、首尾帧提示词模板

### IN（首帧）
```
[LOCK_V1 该角色锁定词]
[景别] [机位] 
[EXP_* 肌肉级描述] [视线方向] [姿势/手部状态]
[SCN_LOCK_V1 环境] [SCN_LOCK_V1 光线]
[画质后缀]

参考图：FACE_REF_{ID}.png（或上一镜 OUT）
```

### OUT（尾帧）— 只改三处
```
[LOCK_V1 同上，一字不改]
[景别] [机位]  ← 一般不变；若本镜有运镜则按运镜结束位置描述
[EXP_* 结束表情] [结束视线] [结束姿势/手部]
[SCN_LOCK_V1 同上，一字不改]
[画质后缀]

参考图：同镜的 IN（保证同光同衣同场景）
```

**纪律：LOCK_V1 与 SCN_LOCK_V1 在 IN/OUT 中必须一字不改。改的只能是"表演层"（表情/姿势/视线/画面元素）。**

## 六、完整示例（一块 = B01，4 镜）

| 镜 | 时长 | 景别 | 表情 | IN 关键点 | OUT 关键点 |
|---|---|---|---|---|---|
| SH01 | 3.75s | ECU | `EXP_GRIEF_M` 1 | 特写脸，雨水滑落，视线微低 | 脸颊水珠下移，视线更低一点 |
| SH02 | 3.75s | CU | `EXP_GRIEF_M` 2 | 抬眼直视镜头，嘴唇微抿 | 喉结吞咽，眼框水光更亮 |
| SH03 | 3.75s | MS | `EXP_RESOLVE_M` 2 | 中景，肩部未放下，手拎外卖袋 | 手收紧袋口，下颌前送 |
| SH04 | 3.75s | CU | `EXP_SHOCK_M` 2 | 过肩，前景肩虚，焦点在他脸 | 眼睛睁圆，嘴微张（= B01_OUT） |

- SH01_OUT ↔ SH02_IN：**同场景同光，表情跨 1 级（M1→M2），合法**
- SH02_OUT ↔ SH03_IN：景别跳 CU→MS，但同场景同人同衣，**链长已达 2，可继续**
- SH03_OUT ↔ SH04_IN：景别 MS→CU + 机位改 OTS，**这是断链点**（信息量跳变），SH04_IN 用 FACE_REF 重开
- SH04_OUT = B01_OUT → 与 B02_IN 核 6 项接缝

## 七、第 ③ 步门禁

- [ ] 每块有 `B{NN}_IN.png` + `B{NN}_OUT.png`，共 12 张（6 块）
- [ ] **块间接缝已核 6 项**：光线方向/色温/服装/姿态/道具/表情基调
- [ ] 每镜有 `frame_in` + `frame_out`，共 48 张（24 镜）
- [ ] `SH0N_OUT ≈ SH0(N+1)_IN`（人或图已比对）
- [ ] 每块 4–6 镜，`dur_sec` 由 `dur_bar` 算出，块内和 = 15.000s
- [ ] 每镜有 `expr_code` + `expr_int`，一块内表情跨级 ≤1
- [ ] 每块有 BGM 意图（`bgm_layer` + `bgm_cue`）+ 音效点 + 环境声
- [ ] 首尾帧提示词含 `LOCK_V1` 与 `SCN_LOCK_V1`（逐字）
- [ ] 每镜 `char_ids` ≤2
- [ ] 所有 frame 文件路径真实存在

## 八、六个翻车与修法

| 症状 | 病因 | 修法 |
|---|---|---|
| 尾帧和下一镜首帧接不上 | 没做接缝校验，靠视频模型自己猜 | 第 ③ 步就核 6 项，不合格重出图 |
| 块内第 3 镜开始变脸 | 继承链超过 4 镜 | 主动断链，用 FACE_REF 重开 |
| 同一块内光线跳了 | 每镜各写光线词 | 光线词提到 `SCN_LOCK_V1`，全块/全场景共用 |
| 尾帧里手是糊的 | 尾帧没检查手部 | 尾帧必检手部；糊了重出该镜 OUT |
| 换装后脸不对 | 继承时带了旧服装图 | 换装必断链，用新 OUTFIT 的九宫格作参考 |
| 块界听起来像新的一集 | BGM 每块独立生成 | BGM 按整集 48 小节做，块只是切片 |
