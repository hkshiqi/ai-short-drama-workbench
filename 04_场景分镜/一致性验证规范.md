# 一致性验证规范（第 ⑤ 步核心）

> 你说的"确保所有 15 秒的片段都经过验证，符合第三步和第四步的要求" ——
> 这份文件就是那个"验证"的可执行判据。**不能靠感觉，必须六道验证全绿才入池。**

---

## 验证总览

| 道 | 名称 | 比对对象 | 判定 | 不合格处理 |
|---|---|---|---|---|
| **A** | 计划 vs 实际 | 第③步的 IN/OUT ↔ 实际生成的首尾帧 | 逐项核 6 维 | 弃，重抽 |
| **B** | 块级接缝 | 前块实际 OUT ↔ 后块计划 IN | 核 6 项 | 重抽或回第③步 |
| **C** | 角色一致 | 实际画面 ↔ `外观锁定词.md` | 逐项核 8 项 | 弃，查第④步 |
| **D** | 物品与场景 | 实际画面 ↔ 物品三视图 / 场景三视图 | 逐项核 | 弃，查第②步 |
| **E** | 声音一致 | 配音 ↔ 音色表 / expr_code 映射 | 逐项核 + 波形 | 重配或回第②步 |
| **F** | 时长与节拍 | 实测时长 ↔ 节拍网格 | 数值判定 | 回第③步修 `dur_bar` |

**一票否决**：A / B / C / D 任一道有"❌" → 该镜不入池。
**E / F** 可先入池再修（不影响重抽视频）。

---

## 验证 A · 计划 vs 实际（最重要）

**为什么这是第一道**：第 ③ 步出的首尾帧就是你签过字的验收标准。
实际生成的视频首尾帧和它不一样 → 说明这个视频"不是你批准的东西"，无论它多好看。

### 操作
```bash
# 导出实际首帧
ffmpeg -i SH0N.mp4 -frames:v 1 SH0N_actual_IN.png
# 导出实际尾帧
ffmpeg -sseof -0.1 -i SH0N.mp4 -frames:v 1 SH0N_actual_OUT.png
```

### 比对 6 项
| # | 项 | 判据 | 合格 | 轻微偏差 | 不合格 |
|---|---|---|---|---|---|
| 1 | 景别与构图 | 人物占画面比例、位置 | 差 <5% | 差 5–15% | 差 >15% 或换机位 |
| 2 | 表情 | 对照 `expr_code` 肌肉描述 | 3 项以上肌肉特征吻合 | 2 项吻合 | ≤1 项吻合或表情全错 |
| 3 | 姿势与手部 | 头部朝向、肩线、手的位置 | 一致 | 手位置略变 | 手势变了 / 手糊 |
| 4 | 服装 | 颜色、款式、褶皱 | 一致 | 细节略变 | 颜色或款式不对 |
| 5 | 道具 | 手里/桌上/身上的物件 | 存在且位置对 | 位置略变 | 缺了或换了 |
| 6 | 光线 | 光源方向、色温、明暗比 | 一致 | 略暖/略冷 | 方向反了 |

**判定**：6 项中 ≥5 项"一致"，其余最多"轻微偏差" → 通过。否则弃。

## 验证 B · 块级接缝

```
前块实际尾帧  ↔  后块计划首帧
B01_actual_OUT.png  ↔  B02_IN.png
```

### 比对 6 项（与验证 A 同维度，但比的是"跨块能否接上"）
```
□ 光线方向一致
□ 色温一致
□ 服装同一套
□ 姿态能接（前块人往左，后块人在左侧）
□ 道具连续（手里东西没凭空变）
□ 表情基调跨级 ≤1
```

**不合格处理**
- 若 `B02_IN` 本身没问题 → 说明 B01 抽卡选错了条 → **重抽 B01 末镜**
- 若 `B02_IN` 本身与 `B01_OUT` 接不上 → **回第 ③ 步重出 B02_IN**

## 验证 C · 角色一致性（8 项逐项核）

| # | 项 | 判据 |
|---|---|---|
| 1 | 脸型 | 长脸/圆脸/方脸，颧骨高度、下颌角 |
| 2 | 眼睛 | 单/双眼皮、眼型、眼距 |
| 3 | 眉毛 | 粗细、眉形、眉尾走向 |
| 4 | 鼻子 | 鼻梁高度、鼻头形状 |
| 5 | 嘴 | 唇厚、唇形、嘴角 |
| 6 | 发型 | 长度、分线、纹理 |
| 7 | 标志物 | 疤/痣/眼镜/耳饰/手表 —— **必须存在且位置对** |
| 8 | 体型 | 身高感、肩宽、胖瘦 |

**判定：8 项里缺 ≥2 项 → 弃。**
（备注：AI 生成的"像"是概率性的，要求 8/8 不现实，但缺 2 项以上观众就能看出来换人了）

## 验证 D · 物品与场景一致性

### 物品（每个出现物品的镜）
```
□ 形态（形状、比例、部件）对得上三视图
□ 颜色对得上（色差不能肉眼可辨）
□ 文字类：文字内容逐字正确（错一个字 = 发布事故）
□ 手持状态自然（手指位置、握法）
```

### 场景（每个镜）
```
□ 空间布局对得上三视图（陈设位置、左右关系）
□ 光源方向与 LIGHT_REF 一致（这是最容易错的）
□ 色调与 SCN_LOCK 一致
□ 大气（雨/雾/尘）一致
```

**判定：物品文字错 = 一票否决。光源方向反了 = 一票否决。**

## 验证 E · 声音一致性

### 5 项
| # | 项 | 判据 |
|---|---|---|
| 1 | 音色 | 与 `音色表.md` 同角色同音色（不可换声） |
| 2 | 情绪参数 | 语速/停顿/尾音与 `expr_code` 映射表一致 |
| 3 | 时长 | wav 实测时长 ≤ 该镜 `dur_sec`（长了要重配或拆句） |
| 4 | 三对齐 | 音频起 / 嘴型动 / 字幕出 三者偏差 <0.15s |
| 5 | 电平 | -6 dB 峰值 / -16 LUFS，无爆音、无削波 |

## 验证 F · 时长与节拍

```bash
ffprobe -v error -show_entries format=duration -of csv=p=0 SH0N.mp4
```

| 判据 | 合格范围 |
|---|---|
| 单镜时长 | `dur_sec ± 0.08s` |
| 块内总长 | `15.000 ± 0.05s` |
| 切点位置 | 落在小节线上（±0.05s） |
| 单镜时长集合 | 只能是 {1.875, 3.750}（4 小节镜可用 5.625） |

**不合格 → 回第 ③ 步修 `dur_bar`，不许在剪辑里变速硬凑**（变速毁画质、毁情绪）。

## 返修回退表（纪律：必须回到出问题的层，不许现场打补丁）

| 失败类型 | 回退到 | 动作 |
|---|---|---|
| 单镜崩（脸/手/动作/多余肢体） | 第 ⑤ 步 | 只重抽该镜 |
| A 验证：计划尾帧本身就有问题 | **第 ③ 步** | 重出该镜 `frame_out`，再重抽 |
| B 验证：块间接缝接不上 | **第 ③ 步** | 重出后块 `IN`，再重抽该块首镜 |
| C 验证：角色跨镜漂 | **第 ④ 步** | 查提示词是否被改字（最常见），或参考图权重 |
| D 验证：物品/场景跑偏 | **第 ② 步** | 查锁定词是否漏了关键特征 |
| E 验证：声音不一致 | **第 ② 步** | 查音色表/参数映射 |
| F 验证：时长超网格 | **第 ③ 步** | 查 `dur_bar` 计算 |

**为什么不能现场打补丁**：
现场打补丁（比如"这条勉强能用，后期修一下"）→ 观众看到的就是"这一块有点怪"→ 而且会在后面 5 块重复同样的错误，因为你没有回到根因层。

## 抽卡台账（可复现的唯一保证）

```csv
1,1,1,2,image,即梦,seedream-4,842114,a1b2c3,"{...}",8.5,选,B01_SH01_IN.png,—,—
1,1,1,1,video,可灵,kling-2.5-pro,559021,d4e5f6,"{dur:5,mode:'pro',first_frame:'B01_SH01_IN.png',last_frame:'B01_SH01_OUT.png'}",8.0,选,—,B01_SH01_OUT_actual.png,—
```

**纪律**
- 选定那一行必须记全 `seed + 参数 + prompt_hash`，否则下次微调重跑不出来
- `frame_in` / `frame_out` 字段要记录**实际用的是哪张图**（计划图还是上一镜实际尾帧）
- 每条候选都记，不只记选中的（复盘时才知道哪个方向的尝试无效）
