# 分镜表规范（S4）

## 一、分镜表列定义（CSV，UTF-8 with BOM，Excel 直接开）

```csv
ep,scene,shot,dur,shot_size,camera,move,first_frame_prompt,video_prompt,negative,char_ids,outfit,line,sub_text,sfx,bgm_cue,product,level,note
```

| 列 | 必填 | 说明 |
|---|---|---|
| `ep` | ✓ | 集号 |
| `scene` | ✓ | 场号 |
| `shot` | ✓ | 镜号（集内连号） |
| `dur` | ✓ | 时长秒，2–5 |
| `shot_size` | ✓ | 特写/近景/中景/中全/全景 |
| `camera` | ✓ | 平视/俯拍/仰拍/过肩/侧逆 |
| `move` | ✓ | 固定/缓推/缓拉/横移/跟（**优先固定**） |
| `first_frame_prompt` | ✓ | **首帧图提示词**：锁定词 + 人物状态 + 环境 + 光线 + 构图 |
| `video_prompt` | ✓ | 图生视频的运动描述：谁 + 做什么 + 幅度 + 时长感 |
| `negative` | ✓ | 负向词（默认模板见下） |
| `char_ids` | ✓ | 出场人物 id，逗号分隔，≤2 |
| `outfit` | | OUTFIT_A/B/C |
| `line` | | 台词原文，无则 `—` |
| `sub_text` | | 字幕文本（显式写出，别让 S5 从台词抓） |
| `sfx` | | 音效：雨声/门铃/心跳/whoosh/stinger |
| `bgm_cue` | | 卡点 cues：进/BEAT_DROP/降/停 |
| `product` | | 产品 id |
| `level` | | L1/L2/L3 |
| `note` | | 备注 |

## 二、首帧提示词构造公式（照抄，别自由发挥）

```
[LOCK_V1 该角色锁定词] + [本镜景别/机位/构图] + [人物状态：表情+姿势+视线] + [环境：地点+时间+天气+关键道具] + [光线：光源方向+色温+质感] + [画质后缀]
```

**画质后缀（全剧统一，一行不改）**
```
电影感, 35mm 胶片质感, 浅景深, 高细节皮肤纹理, 自然光, 8k, 竖构图 9:16
```
英文版（MJ/Runway）：
```
cinematic, 35mm film grain, shallow depth of field, detailed skin texture, natural light, 8k, vertical 9:16
```

## 三、视频运动描述公式（图生视频用）

```
[主体] + [动作：幅度小、单一] + [次要运动：头发/衣角/雨/烟] + [镜头：固定 或 极缓推] + [时长感]
```

好例：`林昭缓缓抬眼看向镜头，幅度很小，雨水从他发梢滴落，镜头固定，5秒。`
烂例：`林昭冲进巷子推开三个人然后回头大喊`（多主体+大位移+复杂交互 = 必崩）

## 四、负向词默认模板

```
变形, 多余手指, 多手多脚, 脸部扭曲, 五官漂移, 双人融合, 文字水印, 字幕, logo, 塑料感皮肤, 过曝, 模糊, 低分辨率, 动漫风, 3D渲染, 卡通
```
英文：
```
deformed, extra fingers, fused bodies, distorted face, melted features, text, watermark, logo, plastic skin, overexposed, blurry, lowres, anime, 3d render, cartoon
```

## 五、一致性 5 条铁律

1. **锁定词逐字复现**。S4 生成时我按 `char_ids` 自动拼锁定词，人工别改字。
2. **同场景同光线**。一场戏的所有镜共用同一段环境+光线描述。
3. **同场景景别不跳级**。特写→中景→特写可以，特写→全景→特写会让观众丢空间感。
4. **正反打走"半侧 + 过肩"**，不许 180° 纯侧脸（AI 侧脸最容易崩）。
5. **动作拆镜**：一个动作 = 起势镜 + 结果镜，中间留给剪辑。

### `场景设定.md` 模板
```md
## SCN_CITY_ALLEY_NIGHT · 城中村巷口·夜·雨
- 环境词：狭窄巷子，两侧是老式瓷砖墙与空调外机，地面积水反光，霓虹招牌残缺
- 光线词：顶灯冷白 + 招牌品红反光，人物脸部半侧冷光
- 色调：青蓝 + 品红点缀
- 声音：雨声底噪 + 远处车流
- 服装：C_LEAD=OUTFIT_A，C_VILLAIN=—
```

## 七、S4 门禁自检
- [ ] 每镜 dur 在 2–5s，单集加总 = 目标时长 ±10%
- [ ] 每镜 char_ids ≤2，出场人物都有卡
- [ ] 首帧提示词含该角色锁定词（逐字）
- [ ] 视频运动描述无多主体/大位移/复杂交互
- [ ] 每镜有 negative、有 sub_text
- [ ] 产品镜头的 visual 与 `植入点位表.csv` 一致
- [ ] CSV 列齐全、无空必填格
