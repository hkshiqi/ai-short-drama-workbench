# 人物表情控制规范（S4 子规范）

> 铁律先行：**AI 视频不会"演"表情，只会"保持"表情。**
> 所以：**表情在首帧定死，视频只准微动，表情变化靠剪辑切镜，绝不靠镜头内演变。**

---

## 一、为什么表情不能靠视频生成

| 事实 | 后果 |
|---|---|
| 首帧图的表情是确定的，可锁 | ✅ 表情在这里定 |
| 图生视频的"表情变化"多帧后必漂，笑容会变成嘴角抽搐 | ❌ 不写"她笑了" |
| 大表情（哭/大笑/暴怒）在视频里 90% 变形 | ❌ 大表情靠首帧定格 + 剪辑切反应镜 |
| 表情是短剧唯一的"演技"来源 | ✅ 所以要在提示词层做肌肉级描述 |

**操作结论**
```
首帧提示词：写表情（肌肉级，见下表）＋ 写强度
视频提示词：只写"微动"——眨眼、呼吸、眼神微移、嘴角极轻抽动、下颌绷紧一点
切换表情：切镜。CU(皱眉) → 硬切 → ECU(眼眶红) → 硬切 → CU(掉泪)
```

## 二、表情编码表（6 基 × 3 强度）

### 编码规则
`EXP_{BASE}_{INT}`：`BASE` ∈ 6 类，`INT` = `L`(1 轻) / `M`(2 中) / `H`(3 重)
例：`EXP_ANGER_H` = 暴怒；`EXP_GRIEF_M` = 中度的悲恸

---

### 1. ANGER 愤怒 / 压抑的怒

| 强度 | 肌肉级描述（中） | 英文 | 适用 |
|---|---|---|---|
| `EXP_ANGER_L` | 眉心微微下压，目光平直不移，嘴唇自然闭合并轻微收紧 | brows drawn slightly down, steady unblinking gaze, lips gently pressed | 隐忍、克制 |
| `EXP_ANGER_M` | 眉心明显下压形成竖纹，上眼睑抬高露出更多眼白，鼻翼微张，下颌绷紧，下唇前推 | brows deeply furrowed, upper lids raised showing more sclera, nostrils slightly flared, jaw clenched, lower lip pushed forward | 短剧主力，"压着怒" |
| `EXP_ANGER_H` | 眉低压近眼睛，眼球突出，鼻翼大幅扩张，嘴唇向后拉露出牙齿，颈部青筋 | brows low over eyes, eyes wide, nostrils wide, lips pulled back showing teeth, neck tendons visible | 爆发；**只用于首帧定格，视频不写变化** |

### 2. GRIEF 悲伤 / 委屈

| 强度 | 描述（中） | 英文 |
|---|---|---|
| `EXP_GRIEF_L` | 内眉头上抬，眼眶微微湿润，嘴角向下拉平 | inner brows lifted, eyes slightly glassy, mouth corners pulled flat |
| `EXP_GRIEF_M` | 内眉头上抬成八字，下眼睑下方饱满有水光，鼻头微红，下唇微颤 | inner brows raised into a peak, lower lids swollen and wet, nose tip pink, lower lip trembling |
| `EXP_GRIEF_H` | 眉心紧皱成川，双眼泛红含泪未落，面颊绷起，嘴唇抖开露出齿关 | brows knitted, eyes red-rimmed with tears held back, cheeks taut, lips parted trembling |

### 3. SHOCK 震惊 / 不敢信

| 强度 | 描述（中） | 英文 |
|---|---|---|
| `EXP_SHOCK_L` | 眉毛微抬，眼睛比平时略睁大，嘴唇轻启 | brows slightly raised, eyes a bit wider, lips slightly parted |
| `EXP_SHOCK_M` | 双眉高抬，眼睛明显睁圆，瞳孔收缩，嘴唇张开成小圆形，下巴微坠 | brows high, eyes rounded, pupils constricted, mouth open in a small O, chin dropped |
| `EXP_SHOCK_H` | 双眉极致上抬，眼白大量露出，嘴唇大张，面部肌肉停滞，颈部后仰 | brows maximally raised, much sclera showing, mouth wide open, facial muscles frozen, head pulled back |

### 4. CONTEMPT 轻蔑 / 嘲讽（反派主力）

| 强度 | 描述（中） | 英文 |
|---|---|---|
| `EXP_CONTEMPT_L` | 单侧嘴角极轻上扬，视线从下往上扫 | one mouth corner lifted faintly, gaze sweeping upward |
| `EXP_CONTEMPT_M` | 单侧鼻翼上提，单侧嘴角拉高，眼睛半阖自上而下看人，下巴抬高 | one nostril raised, one mouth corner pulled up, eyes half-lidded looking down, chin lifted |
| `EXP_CONTEMPT_H` | 整张脸向上皱起，单侧露齿，眼皮半垂，鼻孔对人，头向后仰 | face wrinkled upward, one side teeth showing, lids heavy, nostrils toward camera, head tilted back |

### 5. RESOLVE 坚定 / 决绝（主角高光镜）

| 强度 | 描述（中） | 英文 |
|---|---|---|
| `EXP_RESOLVE_L` | 眼神稳定不眨，嘴唇轻合，下巴平正 | steady unblinking gaze, lips closed, chin level |
| `EXP_RESOLVE_M` | 眼睛微眯，目光定点不移，下颌前送一点，脖颈拉直 | eyes slightly narrowed, gaze fixed, jaw pushed slightly forward, neck straightened |
| `EXP_RESOLVE_H` | 眼睑压低成一条缝但精光外露，眉平直，下颌紧咬，呼吸可见 | lids lowered to a slit with intense focus, brows flat, jaw locked, visible breath |

### 6. TENDER 温柔 / 心动 / 释然

| 强度 | 描述（中） | 英文 |
|---|---|---|
| `EXP_TENDER_L` | 眼角柔和，嘴唇自然微弯，眼神放空 | eye corners softened, lips naturally curved, gaze unfocused |
| `EXP_TENDER_M` | 下眼睑上推形成卧蚕，嘴角对称微上扬，眉放松 | lower lids pushed up, mouth corners symmetrically lifted, brows relaxed |
| `EXP_TENDER_H` | 眼睛弯成弧，笑意到眼底，脸颊上提，唇微启露齿 | eyes curved into crescents, smile reaching the eyes, cheeks lifted, lips parted showing teeth |

## 三、表情曲线（一块内的表演设计）

**规则：一块（15s）内，同一角色表情基调最多跨 1 级。**
跨 2 级 = 情绪跳跃 = AI 漂 + 观众出戏。

### 三种合法曲线

```
① 递进（最常用）      L → M
   例：EXP_ANGER_L → EXP_ANGER_M →（切镜）EXP_SHOCK_M

② 反转（打脸用）      A_H → 切镜 → B_H
   例：反派 EXP_CONTEMPT_H → 硬切 → EXP_SHOCK_H
   （不同角色之间的反差，不是同一角色内变化）

③ 压制（憋屈用）      M 恒定不升
   例：连着 3 镜 EXP_ANGER_M 不变，靠台词和景别推进
   → 观众"替他憋"，这是短剧最有效的手法
```

### 一集的表情分布建议（12 集集均）
| 表情 | 占比 | 说明 |
|---|---|---|
| ANGER | 30% | 压抑型为主（L/M），H 只在爆发镜 |
| GRIEF | 20% | 委屈是短剧的情绪引擎 |
| CONTEMPT | 20% | 反派全靠这个 |
| RESOLVE | 15% | 主角高光 |
| SHOCK | 10% | 反应镜 |
| TENDER | 5% | 甜宠剧提到 25%，打脸剧压到 5% |

## 四、表情与景别的绑定（写块卡时直接套）

| 表情强度 | 必用景别 | 理由 |
|---|---|---|
| `L`（轻） | CU 或 MS | 轻微表情需要一点空间才看得出 |
| `M`（中） | **CU 为主**，ECU 补 | 主力，头肩刚好 |
| `H`（重） | **ECU 或 CU 定格** | 大表情必须逼近，且只在首帧定格，视频只微动 |

**禁止**：`H` 级表情放在 MS 以下的景别（表情全丢）；`L` 级表情放 ECU（看不出在演什么）。

## 五、提示词落位（照抄结构）

### 首帧（表情在这里定死）
```
[LOCK_V1 锁定词] + [景别/机位] + [EXP 肌肉级描述 + 强度] + [视线方向] + [人物状态(姿势/手)] + [环境] + [光线] + [画质后缀]
```

示例 `EXP_ANGER_M`：
```
28岁亚洲男性，窄长脸，颧骨清晰，内双细长眼，薄唇，短寸黑发，肤色偏黄白，身高178偏瘦肩宽，
左手腕旧钢表，右眉尾浅疤，
特写镜头，平视机位，
眉心明显下压形成竖纹，上眼睑抬高露出更多眼白，鼻翼微张，下颌绷紧，下唇前推，
视线直视镜头，头微微低 5 度，
城中村巷口夜雨，身后模糊品红霓虹，
顶灯冷白从上方打下，脸侧有品红反光，
电影感，35mm胶片质感，浅景深，高细节皮肤纹理，自然光，8k，竖构图9:16
```

### 视频（只写微动，绝不写表情变化）
```
✅ 正确：他保持这个表情不动，眼睑快速眨了一下，喉结微微吞咽，雨水从下颌滑落，镜头固定，3.75秒。
✅ 正确：他眼底的水光更亮了一点，眼眶没有更红，嘴唇仍然抿住，呼吸让肩膀极轻起伏，3.75秒。
❌ 错误：他的愤怒逐渐变成悲伤，眼眶慢慢红了，眼泪流下来。（必崩）
❌ 错误：他由生气转为微笑。（必崩）
```

### 表情变化类镜头的正确写法
```
镜 A（3.75s）：CU + EXP_SHOCK_M 首帧，视频=「他眼睛睁圆停住，嘴唇保持张开，只有喉结动了一下」
镜 B（1.875s）：ECU + EXP_GRIEF_M 首帧，视频=「眼眶湿润，泪水停在睫毛上未落，只有睫毛微颤」
镜 C（1.875s）：ECU + EXP_GRIEF_H 首帧，视频=「一滴泪从眼角滑下，脸颊肌肉绷起，镜头固定」
→ 三镜硬切 = 观众看到的"表情渐变"，成本低、崩率几乎为 0。
```

## 六、表情 5 大翻车与修法

| 症状 | 病因 | 修法 |
|---|---|---|
| 笑容变成嘴角抽搐 | 视频里写了"笑" | 笑容只在首帧定格，视频写"嘴角保持上扬，只有脸颊极轻上提" |
| 眼泪流成白线/糊脸 | 写"流泪" | 改"泪水停在睫毛上未落"（静态），或切镜用 ECU 定格一滴泪在脸颊 |
| 皱眉变成整脸皱 | 描述太笼统（写"愤怒"） | 改肌肉级：只写"眉心下压+上睑抬高+下颌绷紧"，其余部位写"面部其余部分放松" |
| 一镜内表情跳变 | 视频提示词里有情绪动词 | 删掉所有"变成/转为/逐渐/慢慢" |
| 跨镜表情不一致 | 每镜各写一套 | 表情描述做成可复用片段，与 `expr_code` 一一对应，机器拼装 |

### 表情描述的"隔离后缀"
每条表情提示词末尾加一句，把不该动的部位锁住：
```
面部其余部分保持放松，无额外皱纹，眼皮不自主抽动。
the rest of the face relaxed, no extra wrinkles, no involuntary twitching.
```
