# 剧本规范（S1）

## 一、结构模板（单集 90s / 18–24 镜）

| 位置 | 时长 | 职能 | 硬要求 |
|---|---|---|---|
| 冷开场 | 0–3s | 直接进戏，**不许空镜不许片头** | 第一帧就是人+冲突 |
| 钩子 | 3–12s | 抛异常/羞辱/危机 | 一句台词能独立成标题 |
| 铺垫 | 12–35s | 给信息、给误会、给压力 | 每 8s 一个小信息点 |
| 加压 | 35–65s | 反派得意、主角憋屈 | 至少 1 次"观众替主角尴尬/愤怒" |
| 反转 | 65–82s | 身份/证据/外援落地 | 反转必须有前置铺垫（不许凭空） |
| 硬钩 | 82–90s | 新危机/新身份揭示 | 断在最难受的一帧 |

## 二、台词规则
1. 单句 ≤ 22 字（竖屏一屏字幕装得下）。
2. 一镜一句，不许两人长对白同镜（AI 生成对不上口型）。
3. **信息靠冲突传递**，不许旁白交代背景。
4. 每集至少 2 句"可截屏金句"（做封面/投流素材用）。

## 三、AI 生成友好约束（写剧本时就为 S4 铺路）
| 约束 | 为什么 |
|---|---|
| 每镜 2–5 秒 | 长镜头 AI 必崩 |
| 单镜内人物 ≤ 2 | 三人以上同框脸必糊 |
| 避免复杂连续动作（打斗、奔跑、多人调度） | 动作一致性是 AI 视频弱项，改成"动作起势 + 切反应" |
| 避免手持镜头/快速摇镜 | 运动幅度大就变形，用固定机位 + 人物动 |
| 场景数每集 ≤ 4 | 换景 = 换一致性风险 |
| 特写优先 | 特写脸最稳，也最适合 AI |

### `01_剧本/script.json`
按 `PIPELINE.md` 的 schema 导出。**这是机器读的唯一格式，改剧本必须同步改 json。**

## 五、S1 门禁自检清单
- [ ] 每集有且仅有 1 个硬钩，类型不连续重复
- [ ] 单集时长在规格 ±10%
- [ ] 每镜 2–5s，单镜人数 ≤2
- [ ] 每集场景 ≤4
- [ ] 主角欲望-阻碍在每集都被重新施压一次
- [ ] 反转有前置铺垫
- [ ] 无禁忌词、无疗效承诺
- [ ] 至少 2 句金句
