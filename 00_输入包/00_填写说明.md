# 00_输入包 · 填写说明

这里是**唯一的入口**。我在这个目录里读你的原始意图，其它目录都是我的产出。

## 填写规则
1. **能给链接就给链接**，比描述准十倍（对标成片、参考画面、参考音色、竞品详情页）。
2. **不要为了"填完整"编造**。没想清楚就写「未定」，我会按默认值推演并在产物里标 `【默认值·待确认】`，你回头一眼就能改。
3. 每个文件末尾都有 `## 待定项` 区，把犹豫的写那儿，别塞进正文。
4. 产品/品牌/人物名称可以直接写真实名，我按真实名做植入；不想露真名就写代号（如 `BRAND_A`），我在成片里统一替换。

## 文件清单
| 文件 | 必须 | 内容 |
|---|---|---|
| `01_题材与对标.md` | P0 | 赛道、对标链接、爆点方向、禁碰题材 |
| `02_出片规格.md` | P0 | 集数、时长、画幅、风格、语种、字幕样式 |
| `03_产品资料.md` | P0 | 品牌、品类、卖点、价格、挂车、禁忌词 |
| `04_角色与演员.md` | P0 | 主角/反派/配角内核、是否真人脸、可选演员照 |
| `05_工具栈与合规.md` | P0 | 可用工具账号、平台、行业红线 |
| `06_资产清单.md` | P1 | 已有图片/音频/视频素材的路径与权属 |

## 什么时候算"填完"
P0 五个文件里**没有一个格子是空的**（写"未定"也算填了）。填完告诉我一句「输入包好了」，我就开跑第一段。
