## 一、为什么是九宫格而不是三视图

三视图（正/侧/背）只覆盖 3 个角度。**AI 崩脸恰恰发生在非正视角度**，尤其 3/4 侧、仰、俯。

九宫格 3×3 覆盖 9 个角度，多出的 6 个是"保障视角"：

```
┌──────────┬──────────┬──────────┐
│ 正面全身  │ 3/4 左半身│ 3/4 右半身│   ← 3/4 最常用（正反打、过肩）
├──────────┼──────────┼──────────┤
│ 左侧全身  │ 正面胸像  │ 右侧全身  │   ← 正面胸像 = 首帧参考主力图
├──────────┼──────────┼──────────┤
│ 背面全身  │ 仰角胸像  │ 俯角胸像  │   ← 仰/俯 = 情绪镜（强/弱）
└──────────┴──────────┴──────────┘
```

**生成方法**
```
input  = LOCK 提示词（人设外貌 40–80 字）
        + "九宫格角色设定图，3x3 网格，同一人物九个角度：正面全身/3-4左半身/3-4右半身/
           左侧全身/正面胸像/右侧全身/背面全身/仰角胸像/俯角胸像，纯灰背景，均匀布光，
           服装统一，无表情，无道具"
        + 画质后缀
input 参考图 = 主角照片（有）+ 已选定的 FACE_REF（后续角色用于统一画风）
出 3 版（同提示词，3 个 seed）→ 你选 1 版
```

**每角色必出 3 张成品**
| 文件 | 内容 | 用途 |
|---|---|---|
| `GRID_{ID}_v1~v3.png` | 九宫格 3 版候选 | 你选脸 |
| `FACE_REF_{ID}.png` | 正面高清胸像（选定版的放大重出） | **首帧抽卡的图生图参考，最常用** |
| `FACE_EXPR_{ID}.png` | 6 基表情小图（愤怒/悲伤/震惊/轻蔑/坚定/温柔） | 表情参考 + 反推 18 条 EXP 片段 |

**每套服装单独出一版九宫格** —— 换装是最大的"变脸"风险点，必须有独立视觉锚：
```
GRID_{ID}_OUTFIT_A.png / _OUTFIT_B.png / _OUTFIT_C.png
```

## 二、场景三视图

**为什么场景要三视图**：同一场景会有 6–10 个镜头，光线或布局一乱，观众立刻觉得"不是同一个地方"。

```
① 主视角（机位 A）     该场景最常用机位
② 反打视角（机位 B）   正反打必须的反向机位，不给这张，过肩镜头必崩
③ 俯视全景（布局图）   交代空间关系 + 光源方向，供你自己核对光线是否一致
```

再补一张 `LIGHT_REF.png`：光线参考（光源方向/色温/氛围/反光色）。

**场景锁定词** `SCN_LOCK_V1`（每场景一条，40–80 字）：

```
格式：[空间结构] + [关键陈设] + [材质质感] + [光源方向+色温] + [色调] + [大气（雨/尘/雾）]

示例 SCN_CITY_ALLEY_NIGHT：
狭窄老旧巷子，两侧老式瓷砖墙与生锈空调外机，地面积水反光，残缺霓虹招牌横挂，
顶灯冷白从上方直下，招牌品红从右侧反光，青蓝主调 + 品红点缀，夜雨，空气有雨雾。
```

**场景锁定词只写环境，不写人物、不写情绪、不写镜头。**

## 三、主要物品三视图

**哪些算"主要物品"**（三类，缺一类后面必出问题）
| 类 | 例 | 为什么必须有 |
|---|---|---|
| 产品（带货标的） | 精华水、空气炸锅 | L2/L3 镜头全靠它，形态错 = 事故 |
| 剧情道具 | 旧钢表、遗嘱、手机屏、合约 | 有特写就必须有锚 |
| 贯穿道具 | 每集都出现的物件 | 每集都要对得上 |

**三视图 + 一张手持图**
```
① 正面　② 侧面　③ 45° 俯视（带环境倒影）
④ PROD_HAND.png  手持/使用状态  ← L2 镜头全是手持，这张最常用
```

**文字类物品（包装/合约/手机屏）**：必须单独出高清正面图，**文字要能看清且正确**。
→ 用 Seedream / Nano Banana（文字渲染最准），出图后**逐字核对**，错一个字就是发布事故。

## 四、音色

### 4.1 音色来源三条路
| 路 | 做法 | 适合 |
|---|---|---|
| A · 克隆 | 你给 10s–30s 参考音频 → 克隆 | 要辨识度、要贴合真人 |
| B · 音色库选 | 从 MiniMax / 豆包音色库挑 | 快、稳 |
| C · 参数调 | 给音高/语速/质感参数 | 无参考音频时的兜底 |

### 4.2 音色表（`02_角色/音色表.md`）
```md
| 角色 | 性别/年龄 | 音高 | 语速 | 质感 | 音色ID | 试听文件 | 通过 |
|---|---|---|---|---|---|---|---|
| C_LEAD | 男/28 | 偏低 | 0.95x | 微哑克制 | ______ | lead_试听.mp3 | ☐ |
| C_VILLAIN | 女/45 | 中高 | 1.05x | 尖、齿音重 | ______ | villain_试听.mp3 | ☐ |
```

### 4.3 试听必过 3 句（少一句都不算确认）
| # | 内容 | 验什么 |
|---|---|---|
| 1 | 平静陈述句（8–12 字） | 是不是这个人、有没有口音 |
| 2 | 压抑怒（`EXP_ANGER_M`，8–12 字） | 克制得住吗、会不会念成吼 |
| 3 | 爆发或悲恸（`EXP_GRIEF_H` 或 `EXP_ANGER_H`） | 情绪上限、会不会破音失真 |

### 4.4 情绪参数映射（音色表配套）
| expr_code | 语速 | 句中停顿 | 尾音 |
|---|---|---|---|
| `EXP_ANGER_L/M` | 0.95x | 200ms | 收住、不下沉 |
| `EXP_ANGER_H` | 1.10x | 无 | 破音、上扬 |
| `EXP_GRIEF_M` | 0.88x | 350ms | 颤、下沉 |
| `EXP_RESOLVE_M/H` | 0.92x | 150ms | 平、砸下 |
| `EXP_CONTEMPT_M/H` | 1.05x | 400ms | 拖长、上扬 |
| `EXP_SHOCK_M` | 1.00x | 句首 300ms 吸气 | 短、断 |
| `EXP_TENDER_M` | 0.92x | 250ms | 轻、上扬 |

**纪律：一角色一音色，全剧不换。情绪变化靠语速 ±0.1 + 停顿 + 尾音，不靠换音色。**

## 五、三份锁定词（冻结清单）

| 文件 | 版本 | 条数 | 内容 |
|---|---|---|---|
| `02_角色/外观锁定词.md` | `LOCK_V1` | 每角色 1 条 | 脸型/五官/发型/肤色/体型/标志物，中英双版 40–80 字 |
| `02_角色/表情片段库.md` | `EXPR_LOCK_V1` | 18 条（6 基 × 3 强度） | 肌肉级描述，中英双版 |

**只写"可见的、稳定的"特征。绝不写：情绪、动作、镜头、光线情绪化描述**（那些属于第 ④ 步镜头层）。

**改版规则**
```
要改锁定词 → 升 LOCK_V2 → 在文件里记 diff（改了什么、为什么）
         → 重跑全部受影响镜（不是只重跑这一镜）
```

## 八、常见问题

| 症状 | 原因 | 处理 |
|---|---|---|
| 九宫格里九个角度不像同一个人 | 提示词没锁死 + 缺参考图 | 用已选定的 `FACE_REF` 作参考重出 |
| 3/4 侧脸认不出 | 该角色特征不够"可辨" | 加一个强标志物（疤/痣/眼镜/发型）写进锁定词 |
| 换装后不像同一人 | 服装词覆盖了外貌词 | 服装单列 `OUTFIT_*`，锁定词每次逐字复现 |
| 场景反打视角和主视角不像同一空间 | 缺反打图，靠文字猜 | 必须出反打图，S4 直接参考 |
| 产品文字出图后是乱码 | 模型文字能力弱 | 换 Seedream / Nano Banana，文字单独出图再合成 |
| 音色试听 3 句里第 3 句失真 | 情绪上限不够 | 换音色，或把 H 级爆发改成 M 级 + 剪辑加强 |
