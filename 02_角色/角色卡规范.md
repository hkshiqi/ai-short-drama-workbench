# 角色卡规范（S2）

## 一、角色卡必须包含的 9 个字段

| 字段 | 说明 | 例 |
|---|---|---|
| `id` | 唯一标识，全流程引用 | `C_LEAD` |
| 人设内核 | 谁+身份+欲望+阻碍+弱点，一句话 | 外卖员 / 真身集团少东 / 要手术费 / 被继母设局 / 死要面子 |
| 外貌 | 年龄、身高体型、脸型、五官、发型、肤色 | 28 男，178，窄长脸，内双，短寸 |
| **外观锁定词** | **40–80 字，逐字复用到每条分镜提示词** | 见下 |
| 服装 | 每套一套词，编号 | `OUTFIT_A` 深灰工装夹克+黑T+旧帆布鞋 |
| 标志物 | 一眼识别的物件 | 左手腕旧钢表 |
| 音色 | 配音参数（语速/音高/质感）或音色 ID | 男，偏低，语速慢，沙哑 |
| 行为习惯 | 3 个小动作（AI 可用作运动描述） | 焦虑时摸表 / 说话前先笑一下 / 转身前顿 0.5s |
| 关系 | 与其它角色的连接与张力 | 对继母：表面恭顺，眼底冷 |

## 二、外观锁定词（全流程最关键的一行）

规则：
1. **一条锁定词只管一个人**，不含其它人。
2. 只写**可见的、稳定的**特征：脸型、五官、发型、肤色、体型、标志物。**不写情绪、动作、镜头、光线**（那些属于分镜层）。
3. 40–80 字，中英双版（中文贴即梦/可灵，英文贴 MJ/Runway）。
4. **不许中途改字**。要改 = 全剧重跑。改的时候升版本号 `LOCK_V2` 并在 `外观锁定词.md` 记 diff。

### 示例
```
LOCK_V1 · C_LEAD（中文）
28岁亚洲男性，窄长脸，颧骨清晰，内双细长眼，眉骨略高，薄唇，短寸黑发，肤色偏黄白，
身高178体型偏瘦但肩宽，左手腕戴旧钢带手表，右眉尾有一道浅疤。

LOCK_V1 · C_LEAD（EN）
28-year-old East Asian man, narrow long face, defined cheekbones, thin double-eyelid eyes,
slightly high brow ridge, thin lips, short buzz-cut black hair, warm pale skin, lean 178cm
build with broad shoulders, worn steel-band watch on left wrist, faint scar on right eyebrow tail.
```

## 三、锁脸工作流
1. **有真人照片** → 图生图（即梦"参考图"/Vidu 参考生视频/MJ `--cref`），锁定词用于补充描述。
2. **无照片** → 我先出 3 版定妆图（正面/半侧/全身，同一提示词三个 seed），你挑 1 版。
3. 选定后 → 回写锁定词（把定妆图上真实存在的特征写进去，别写图上没有的）→ 冻结为 `LOCK_V1`。
4. 之后每个镜头提示词 = `[锁定词] + [本镜景别/机位] + [本镜动作] + [光线氛围]`。

## 五、S2 门禁自检
- [ ] 每个出场人物都有卡（含只有 1 镜的路人 → 用 `EXTRA_01` 通用卡）
- [ ] 主角/反派/女主各有 `LOCK_V1` 中英双版
- [ ] 锁定词只含可见稳定特征，无情绪/光线/镜头
- [ ] 服装每套有独立编号
- [ ] 音色可落地（有 ID 或参数）
- [ ] 至少 3 个可用作运动描述的行为习惯
